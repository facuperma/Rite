# Rite

App de notas para Android (Kotlin + Compose + Room) que va a hablar con Mateo (LLM local) y con Claude Code. Plan completo en PLAN_NOTAS_MATEO.md.

Etapa 0: notas, carpetas, etiquetas, colores, fijadas, papelera de 30 dias, busqueda, listas con casillas.

Compilar: `gradlew.bat assembleDebug` (en esta PC con `JAVA_TOOL_OPTIONS=-Djdk.net.unixdomain.tmpdir=C:/gtvtmp`). Tests: `gradlew.bat testDebugUnitTest`.
